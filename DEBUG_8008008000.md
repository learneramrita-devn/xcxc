## 🔍 Step-by-Step Debug

### Step 1: Check Console Logs

**Open Browser Console (F12) and look for:**

```
=== TERMS ACCEPTED - STARTING REGISTRATION ===
Mobile: 8008008000
Registration Type: [api_partner/whitelabel/corporate]

=== REGISTER USER FUNCTION CALLED ===
- Is Tenant Registration: true

=== CALLING API ===
API Endpoint: /ums/v1/tenant/save

=== API RESPONSE SUCCESS ===
Response: {...}
```

**If you DON'T see these logs:**
- Registration didn't complete
- Check if Terms were accepted
- Check if Continue button was clicked

---

### Step 2: Check Network Tab

**Open DevTools → Network Tab → Filter: Fetch/XHR**

**Look for:**
```
POST /ums/v1/tenant/save
Status: 200 (or 400/500 if error)
```

**Click on the request and check:**
1. **Request Payload** - Should have all tenant data
2. **Response** - Should have tenantId or userId
3. **Status Code** - Should be 200

---

### Step 4: Check Registration Type

**The issue might be:**
- You selected "Travel Agent" instead of "API Partner/WhiteLabel/Corporate"
- This would call User API instead of Tenant API

**Verify in console logs:**
```
- Resolved Type: api_partner (or whitelabel/corporate)
- Is Tenant Registration: true
API Endpoint: /ums/v1/tenant/save
```

**If it shows:**
```
- Resolved Type: agency
- Is Tenant Registration: false
API Endpoint: /api/v1/users/create
```
**Then you created a USER, not a TENANT!**

## 🔧 Fixes to Apply

### Fix 1: Ensure Correct Registration Type

**When registering tenant, make sure you select:**
- ✅ API Partner
- ✅ WhiteLabel Partner
- ✅ Corporate

**NOT:**
- ❌ Travel Agent (this creates User, not Tenant)

---

### Fix 2: Add More Visible Logging

**Add this to RegistrationForm.jsx after API call:**

```javascript
const handleTermsAccept = async () => {
  setLoading(true);
  try {
    console.log('🚀 STARTING REGISTRATION...');
    const res = await registerUser({ mobile, tenantId, form: registerData, registrationType });
    
    console.log('✅ REGISTRATION SUCCESS!');
    console.log('Response:', res);
    
    // Show alert for debugging
    alert('Registration Successful! User/Tenant ID: ' + (res?.userId || res?.tenantId || 'N/A'));
    
    const regType = registrationType || registerData.selectedAgentType;
    const isTenant = ['api_partner', 'whitelabel', 'corporate'].includes(regType);
    const successMessage = isTenant ? 'Tenant successfully created!' : 'User successfully created!';
    
    console.log('📢 Showing toast:', successMessage);
    showToast(successMessage, 'success');
    
    setRegisteredUserId(res?.userId || res?.tenantId || null);
    
    setTimeout(() => {
      console.log('🔄 Redirecting to success screen...');
      setStep(STEPS.SUCCESS);
    }, 1500);
    
  } catch (err) {
    console.error('❌ REGISTRATION FAILED!');
    console.error('Error:', err);
    alert('Registration Failed: ' + err.message);
    showToast(err.message || 'Registration failed. Please try again.', 'error');
  } finally {
    setLoading(false);
  }
};
```

## 🚨 Common Issues

### Issue 1: Wrong API Called
**Symptom:** Created user instead of tenant
**Cause:** Selected "Travel Agent" instead of "API Partner"
**Fix:** Select correct business type

### Issue 2: API Returns Error
**Symptom:** No success message, error in console
**Cause:** Backend validation failed
**Fix:** Check Network tab response, fix payload

### Issue 3: Toast Not Showing
**Symptom:** Registration succeeds but no toast
**Cause:** Toast component CSS issue or state not updating
**Fix:** Check CSS, add alert() for debugging

### Issue 4: Backend Returns Success but isExist Still False
**Symptom:** Registration API returns 200 but tenant check fails
**Cause:** Backend database issue or cache
**Fix:** Wait 5 seconds and check again, or check backend logs
